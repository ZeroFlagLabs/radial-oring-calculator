# v2.1.6 - Unit suffix selection correction

Corrects the v2.1.5 suffix-selection maintenance change by attaching protection after Qt Designer has loaded the final numeric editors. Unit text stays visible and cannot be selected or partially deleted. Clicking on or beyond the unit moves the caret to the end of the numeric portion. Numeric editing inside the value remains normal. The layout, stepping, tolerance conversion, calculation equations and precision are unchanged.

Download the Windows Portable ZIP, extract the single unsigned EXE and double-click it.
