# v2.1.7 - Display-only input units

Replaces the previous cursor-signal-based suffix protection with independent, non-interactive unit labels. The native numeric editor contains only the number. First-click caret placement, selection, deletion and precise numeric editing now work in angle, nominal, tolerance and both Limits fields. The approved visual layout, calculation equations, precision and tolerance conversion are preserved.

Download the Windows Portable ZIP and extract its single unsigned executable. No installer or separate Python runtime is required.
